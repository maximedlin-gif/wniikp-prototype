Гистограмма яркости и пороги сегментация

Распределение яркости вокселей внутри изделия. Пунктир — пороги классов. По умолчанию найдены методом Оцу; можно подвинуть вручную.

T1 T2

Сегментация среза воздух / материал / плотный

Каждый воксель отнесён к классу по яркости. Фон вне изделия исключён заливкой от границ кадра — порами считаются только замкнутые внутренние полости.

Срез

Псевдоцветовое контрастирование цветовая карта плотности

Монохромный рентгеновский срез раскрашен по плотности: тёмные тона — поры/воздух, тёплые и яркие — плотный материал. Делает перепады внутренней структуры заметнее для оператора, не меняя расчёт.

Гранулометрия пор распределение по размерам

Поры выделены анализом связных компонент. Гистограмма — распределение пор по эквивалентному диаметру (диаметр круга той же площади).

Толщина стенок между порами оценка по EDT

По карте расстояний (евклидово преобразование) для материала. Оценка: удвоенное расстояние от точки материала до ближайшей поры/границы.

Профиль по высоте плотность / пористость

Изделие разбито на горизонтальные слои. Для каждого — доля материала и средняя яркость (прокси плотности). Виден контраст «корочка ↔ рыхлый центр».

Статус и ограничения. Модуль выполняет реальную обработку изображения в браузере: перевод в градации серого, построение гистограммы, сегментацию методом Оцу, поиск пор анализом связных компонент, оценку толщины стенок по карте расстояний. Расчёт корректен для одиночного среза (2D) или стека кадров. Для одиночного среза «объём» — это площадь сечения, а пористость — площадная доля; помечено в протоколе. Полный трёхмерный анализ исходного тома (TIFF-стек / DICOM с размером вокселя), 3D-связность 26-соседства и калибровка по единицам Хаунсфилда выполняются серверным пайплайном (scikit-image / SimpleITK / PoreSpy) — этот прототип демонстрирует логику и интерфейс будущего ПО.  ·  Автор: М.
