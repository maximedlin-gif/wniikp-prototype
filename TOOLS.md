# Инструменты проекта ВНИИКП

Все команды запускать из папки `~/Documents/wniikp-prototype/`. Нужен только `python3` (без внешних пакетов).

## Структура версий
- Корень `/` — **красная** версия (фирменный цвет семьи Горбатова).
- `versions/blue/` — **синяя** версия (сохранена для сравнения).
- Превью обеих: красная `http://localhost:8781/`, синяя `http://localhost:8781/versions/blue/`.
  Поднять сервер: `cd /tmp/wniikp-serve && python3 -m http.server 8781` (отдаёт копию; в `~/Documents/...` — каноничные исходники).

## qa.py — авто-проверка качества
```
python3 qa.py          # красная версия
python3 qa.py --all    # + структура страниц в versions/blue
```
Проверяет: битые внутренние ссылки и #якоря, обязательные SEO-теги, alt у картинок,
контраст WCAG (из CSS-токенов), вес изображений, остатки эмодзи/плейсхолдеров,
согласие на ПДн в формах, один `<h1>`. Код возврата 1 при ошибках — **запускать после любых правок.**
(Контраст считается по корневому `styles.css`.)

## site.json + build.py — единый источник данных
Все реквизиты, меню, подвал — в `site.json`. После правки:
```
python3 build.py
```
Пересобирает на всех страницах: топбар, меню (активный пункт + CTA), подвал,
номер лицензии в «Обучении», контакты в JSON-LD. Идемпотентно, ct-analyzer и versions/ не трогает.
**Менять контакты/меню/лицензию — только в `site.json`, затем `build.py`.**

## monitor.py — мониторинг сайтов семьи Горбатова
```
python3 monitor.py
```
Проверяет доступность и изменение контента 6 сайтов-филиалов (состояние в `monitor_state.json`).
Запускать вручную (например, перед встречей с институтом).

## Смена основного цвета
Дизайн построен на CSS-переменных `--blue*` в `styles.css` (имена исторические, значения — красные).
Поменять тон: правка `:root` + при необходимости хардкод-градиентов hero/flagship. Затем `python3 qa.py`.

## Типовой цикл правки
1. Изменить контент/данные (`site.json` или конкретную страницу).
2. `python3 build.py` (если менялись общие блоки/реквизиты).
3. `python3 qa.py` — убедиться, что 0 ошибок.
4. Скопировать в превью: `cp -p *.html *.css img/* /tmp/wniikp-serve/` (и `versions/` при необходимости).
